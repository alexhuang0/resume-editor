# Implementation Plan

Requirement numbers refer to `design.md` §2 (Locked requirements). Property numbers refer to
`design.md` §8 (Correctness Properties).

Tasks 1–4 are independent of each other and of the bank work. They touch no `schema.ts` and they fix
bugs that are being hit today, so they go first. Tasks 5–9 are the structural chain and **must run in
order**. Tasks 10–12 build on the chain.

The app must build and run after every task. `npm run build` is the gate; the demo step is the proof.
